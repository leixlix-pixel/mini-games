# 조용한 퍼즐

폰으로 여는 퍼즐 다섯 가지. **광고가 없고, 인터넷이 끊겨도 되고, 로그인도 없다.**
설치 없이 링크만 열면 되고, 기록은 그 폰 안에만 남는다(서버가 없다).

**링크** → https://leixlix-pixel.github.io/mini-games/

## 들어 있는 것

| | | |
|---|---|---|
| 🧪 **물병 색 정렬** | 색깔 물을 옮겨 담아 병마다 한 색으로 | 단계마다 색이 늘어난다(4색 → 12색). 빈 병 하나를 한 판에 한 번 더 받을 수 있다 |
| 🔢 **2048** | 밀어서 같은 숫자끼리 합치기 | 스와이프 또는 화살표 키. 한 수 되돌리기 |
| 🧩 **스도쿠** | 가로·세로·네모마다 1~9 | 쉬움·보통·어려움. 메모, 메모 자동 채우기, 힌트, 되돌리기 |
| 🧱 **블록 퍼즐** | 10칸 판에 조각을 끼워 줄 지우기 | 조각을 끌어다 놓는다. 가로든 세로든 한 줄이 차면 사라진다. 한 수 되돌리기 |
| 🔵 **구슬 벽돌깨기** | 구슬을 쏘아 숫자 벽돌 부수기 | 화면을 끌었다 놓으면 발사. 벽돌은 매 판 한 줄씩 내려온다. 초록 +N 은 공이 늘고, 별은 점수만 |

## 광고 앱과 다른 점

- **광고가 하나도 없다.** 멈추지도, 기다리지도 않는다.
- **「광고 보고 되돌리기」가 없다.** 되돌리기는 그냥 버튼이다. 블록 퍼즐은 끝난 판도 한 수 되살린다.
- **인터넷이 없어도 된다.** 한 번 열어 두면 비행기 모드에서도 돌아간다(글꼴만 기본 글꼴로 바뀐다).
- **아무것도 보내지 않는다.** 계정도, 서버도, 통계 수집도 없다.
- **하던 판이 남는다.** 중간에 나가도 다음에 열면 그 자리다.

## 폰에서 앱처럼 쓰기

- **아이폰**: 사파리로 링크 열고 → 공유 버튼 → `홈 화면에 추가`
- **안드로이드**: 크롬으로 열고 → 오른쪽 위 ⋮ → `홈 화면에 추가`

주소창 없이 전체 화면으로 뜬다.

## 소리·진동

홈 화면 아래 `소리` · `진동` 버튼으로 끄고 켠다. 아이폰은 무음 스위치를 켜면 소리가 안 난다.
브라우저는 화면을 한 번 눌러야 소리를 허용하므로, 처음 한 번은 소리가 늦게 날 수 있다.

## 기록이 사라진다면

기록은 브라우저 저장소에 들어 있다. **시크릿/프라이빗 창**으로 열거나, 브라우저의
`사이트 데이터 삭제`를 하면 없어진다. 저장이 아예 막힌 상태에서도 게임은 정상으로 돌아가고,
기록만 안 남는다.
